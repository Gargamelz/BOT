============================================================
  CARPETA DE IMAGENES DEL GAME BOT
============================================================

Aqui debes colocar las capturas de pantalla (screenshots) de
los botones del juego que el bot necesita buscar y clicar.

Flujo del bot:
  Pasos 1-7: Preparar batalla (secuencial)
  Paso 8:    Esperar resultado (escanea victoria/derrota)
  Derrota:   Pasos 9-12 (tap x3 + next) -> vuelve a paso 5 (nivel)
  Victoria:  Placeholder (vuelve a paso 1 por ahora)

IMAGENES NECESARIAS (formato BMP recomendado):
------------------------------------------------------------

--- PREPARACION (pasos 1-7) ---

1. boton_battle.bmp
   -> Boton "Battle" para entrar a la seleccion de batalla

2. boton_solo.bmp
   -> Boton "Solo" para seleccionar modo individual

3. boton_setup.bmp
   -> Boton "Setup" en la pantalla de configuracion

4. boton_expert.bmp
   -> Boton "Expert" para seleccionar dificultad

5. boton_nivel.bmp
   -> Boton de seleccion de nivel

6. boton_auto.bmp
   -> Boton "Auto" para activar modo automatico

7. boton_iniciar.bmp
   -> Boton "Iniciar" para confirmar e iniciar la batalla

--- RESULTADO (paso 8 - el bot busca ambas) ---

8a. pantalla_victoria.bmp
    -> Captura de la pantalla de victoria

8b. pantalla_derrota.bmp
    -> Captura de la pantalla de derrota

--- RUTA DERROTA (pasos 9-12) ---

9/10/11. boton_tap.bmp  (UN solo archivo, se usa 3 veces)
    -> Captura del texto "Tap to proceed"

12. boton_next.bmp
    -> Boton "Next" despues de los taps


COMO HACER LAS CAPTURAS:
------------------------------------------------------------

Metodo 1 - Recorte de Windows (recomendado):
  1. Abre tu juego
  2. Presiona Win + Shift + S
  3. Selecciona SOLO el boton o area que necesitas
  4. Abre Paint
  5. Pega con Ctrl + V
  6. Guarda como BMP (Archivo > Guardar como > BMP)
  7. Ponle el nombre correcto (ej: boton_battle.bmp)
  8. Guardalo en esta carpeta

Metodo 2 - Print Screen:
  1. Abre tu juego
  2. Presiona Print Screen (PrtSc)
  3. Abre Paint
  4. Pega con Ctrl + V
  5. Selecciona y recorta SOLO el boton
  6. Guarda como BMP en esta carpeta

CONSEJOS IMPORTANTES:
------------------------------------------------------------
- Recorta SOLO el boton, no toda la pantalla
- El recorte debe ser lo mas preciso posible
- Usa formato BMP para mejor compatibilidad
- Si el bot no encuentra la imagen, intenta:
  * Hacer una nueva captura con la misma resolucion
  * Aumentar la Variacion en la GUI del bot (50-100)
  * Asegurate de que el juego este en la misma resolucion
  * Usa la funcion de Scroll si el boton no es visible
